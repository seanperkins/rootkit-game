# Fusion, Recipes and Blocks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three slots matching an exact recipe fuse into one much stronger module; modules go back to one-per-loadout, and fusion — triggered by holding a block in the arena — is how you get one back.

**Architecture:** `Exploit` gains a `fused` head that absorbs the VECTOR and TRIGGER columns and carries its own kinds, so a fused row fires with no trigger module in it. Four new stat keys plus a `targeting` enum give twenty recipes their identities; twelve of the twenty need no new runtime code at all. A new `Blocks` state machine spawns a capture point on a cadence, and its payout is either the fusion offer or a card screen seeded toward the recipe you are closest to.

**Tech Stack:** Godot 4.7, GDScript, no image assets. Packed arrays over a uniform grid; no `Area2D`.

**Spec:** `docs/superpowers/specs/2026-08-31-fusion-design.md`

## Global Constraints

- Run tests with `tools/run_tests.sh`. The runner fails on any `SCRIPT ERROR`; a bare `PASS` is not evidence.
- Suites that count assertions carry an `EXPECTED_CHECKS` constant — `test_build.gd` 76, `test_cadence.gd` 26, `test_meta_layout.gd` 4, `test_travel.gd` 8, and no others. **Every task that adds a `_check` to such a suite must raise that constant to match**, or the suite fails on the count. `tests/test_cards_keyboard.gd` has **no** such constant: it uses a `CASES` array (`:14-23`) plus a `finished` dict, so a new case there must be added to `CASES` and must set `finished[...]` on its last line.
- **`tests/test_build.gd:321` pins `Module.STAT_KEYS.size() == 23` and `:329` pins that 22 of them default to zero.** Tasks 4-7 each append one key, so each of those four tasks must raise BOTH numbers by one — ending at 27 and 26. The pin's own comment says it exists to force exactly this review. A task that adds a key without moving the pin reports `test_build FAIL`, not ALL GREEN.
- **`tests/test_slots.gd` pins the behaviour Task 1 removes** (`:65`, `:69`, and the whole `duplicates_allowed()` case at `:72-86`). It is in `SUITES`. Task 1 rewrites it; no later task may leave it asserting the old rule.
- `Module.STAT_KEYS` is a closed set and every key in it must be a field on `ResolvedExploit`. Adding a key without the field makes `_fold` write to nothing.
- The `Module.Slot`, `Module.VectorKind` and `Module.TriggerKind` enums are **appended, never reordered** — their values are stored on modules.
- A fused module has `slot == Module.Slot.VECTOR`. That is load-bearing: `Compiler._fold` already freezes a vector's `cooldown` and `travel` against rank and grows `radius` at a quarter rate, and a fused module wants all three.
- **A fused module may not carry `cadence_mult`.** `Compiler.validate` forbids it on any VECTOR, and the reason (the proportional cooldown floor reads the vector's raw base) applies unchanged. Bake the trigger's cadence into the fused module's `cooldown`.
- Every VECTOR — fused included — must carry `cooldown >= MIN_COOLDOWN / MIN_CADENCE_FRACTION`, which is `0.05 / 0.12 = 0.41667`.
- Defensive magnitudes fold by MAX, offensive ones by sum. The argument is in `Compiler.MAX_FOLD_KEYS`.
- Perf gate: mean 1.13 ms, p95 2.40 ms against an 11 ms budget. Only Task 7 (`homing`) can move it; it is the acceptance criterion for that task.
- Add each new suite to `SUITES` in `tools/run_tests.sh` in the task that creates it.
- No AI attribution in commit messages.

```gdscript
## The exploit and slot holding this id, or [] when nothing does.
func _slot_holding(id: StringName) -> Array:
	for e in exploits.size():
		for sl in Exploit.SLOT_COUNT:
			var em: EquippedModule = exploits[e].at(sl)
			if em != null and em.module.id == id:
				return [e, sl]
	return []

func legal_targets(m: Module) -> Array:
	var out := []
	var home := _slot_holding(m.id)
	for e in MAX_EXPLOITS:
		var ex: Exploit = exploits[e] if e < exploits.size() else null
		for sl in Exploit.SLOT_COUNT:
			if Exploit.slot_type(sl) != m.slot:
				continue
			if ex == null:
				if home.is_empty():
					out.append(Target.new(e, sl, Rule.EMPTY_SLOT))
				continue
			var occupant := ex.at(sl)
			if occupant != null and occupant.module.id == m.id:
				# Ranks are per SLOT. With uniqueness there is only ever one.
				if occupant.can_rank_up():
					out.append(Target.new(e, sl, Rule.RANK_UP))
				continue
			if not home.is_empty():
				continue          # one id, one slot: nowhere else is legal
			if occupant == null:
				out.append(Target.new(e, sl, Rule.EMPTY_SLOT))
			elif not _is_last_interval(occupant):
				out.append(Target.new(e, sl, Rule.REPLACE, occupant.module))
	return out
```

### Task 2: The fused head

**Interfaces:**

- Produces: `Module.is_fused: bool`; `Exploit.head_is_fused() -> bool`; `Compiler.build` taking `trigger_kind` from the VECTOR slot when its module is fused.

**Where the fused module lives, and why not in a field of its own.** A fused
module **is** a VECTOR — `slot == Module.Slot.VECTOR`, which is what buys it the
right rank scaling for free. So it goes in `Exploit.vector`, marked by
`is_fused`, and the TRIGGER slot is simply left empty.

A parallel `Exploit.fused` field was the first design and it was wrong. It put a
`if fused != null` branch into `at`, `equipped`, `has_free_slot_for`,
`is_inert`, `legal_targets`, `_interval_count`, `Compiler.build` and the UI, and
it broke the invariant the whole loadout and level-up screen are built on — that
a row is three slots and `at(i)` names them. `at()` now needs **no change at
all**: `at(0)` is the vector fused or not, `at(1)` is the trigger, `at(2)` is the
payload. The two things `legal_targets` must know — do not offer the trigger
column, do not let the head be replaced — are two boolean reads of
`head_is_fused()`, the same count the parallel field cost, without the field or
the second concept.

```gdscript
## True when this row's VECTOR is a fused module. Such a row needs no TRIGGER
## module — the head carries the trigger_kind — so its trigger column is empty
## and stays empty.
func head_is_fused() -> bool:
	return vector != null and vector.module.is_fused

func is_inert() -> bool:
	if vector == null:
		return true
	return not vector.module.is_fused and trigger == null

func has_free_slot_for(slot: int) -> bool:
	match slot:
		Module.Slot.VECTOR:  return vector == null
		# A fused head absorbed this column; nothing may fill it.
		Module.Slot.TRIGGER: return not head_is_fused() and trigger == null
		_:                   return free_payload_slot() >= 0
	return false
```

```gdscript
## Every row that exactly matches a recipe, paired with what it would become.
func matched_recipes() -> Array:
	var out := []
	for i in exploits.size():
		var r := RecipeTable.match_exploit(exploits[i])
		if r != null:
			out.append([i, r])

## Fusing the row that holds your last INTERVAL trigger frees `interval` but
## leaves nothing firing unconditionally until you re-place it — the deadlock
## _is_last_interval was written for, arriving by a different door. A fused
## module that is itself INTERVAL-triggered replaces what it consumed.
func can_fuse(exploit_index: int, fused: Module) -> bool:
	if exploit_index < 0 or exploit_index >= exploits.size():
		return false
	if fused.trigger_kind == Module.TriggerKind.INTERVAL:
		return true
	var ex: Exploit = exploits[exploit_index]
	var lost := 1 if (ex.trigger != null
		and ex.trigger.module.trigger_kind == Module.TriggerKind.INTERVAL) else 0
	return _interval_count() - lost >= 1

## Consumes all three. Their ids are free from this moment, which is the point:
## the way to use `interval` twice is to fuse the row holding it.
func fuse(exploit_index: int, fused: Module) -> void:
	if not can_fuse(exploit_index, fused):
		return          # never silently clear a row a caller may not fuse
	var ex: Exploit = exploits[exploit_index]
	ex.trigger = null
	for i in Exploit.PAYLOAD_SLOTS:
		ex.payloads[i] = null
	# The head goes into the VECTOR slot it occupies from now on. Assigned LAST,
	# so a refused fusion above leaves the row exactly as it was.
	ex.vector = EquippedModule.new(fused)

## A fused module whose trigger_kind is INTERVAL counts as an interval trigger,
## because it is one.
func _interval_count() -> int:
	var n := 0
	for ex in exploits:
		if ex.head_is_fused():
			if ex.vector.module.trigger_kind == Module.TriggerKind.INTERVAL:
				n += 1
		elif ex.trigger != null \
				and ex.trigger.module.trigger_kind == Module.TriggerKind.INTERVAL:
			n += 1
	return n
```

```gdscript
class_name Blocks extends RefCounted

## The capture point that pays out. One live at a time; hold ground inside it
## while the swarm keeps coming, and the payout is either a fusion or a card.
##
## Pure state: no scene tree, no terrain, no run. The caller injects a placer
## Callable and an RNG, which is what makes the schedule and the drain testable
## without standing up an arena.

## Long enough that the first one lands after the build has something to fuse,
## short enough to arrive inside the first subnet.
const FIRST_SPAWN := 40.0
const INTERVAL := 45.0
const HOLD_SECONDS := 8.0
const RADIUS := 70.0

## Leaving drains at twice the fill rate. Standing off it is a decision, not a
## pause: four seconds away costs the eight you were most of the way through.
const DRAIN_RATE := 2.0

## Far enough that reaching it is a move, near enough to stay on screen. Bounded
## by VIEW_RANGE (620.0, run.gd:37) rather than above it: past that the block is
## off the edge of what the player can see, with no indicator pointing at it.
const MIN_DIST := 400.0
const MAX_DIST := 600.0

var alive := false
var pos := Vector2.ZERO
var progress := 0.0
var elapsed := 0.0
var next_at := FIRST_SPAWN

func reset() -> void:
	alive = false
	pos = Vector2.ZERO
	progress = 0.0
	elapsed = 0.0
	next_at = FIRST_SPAWN

func fraction() -> float:
	return progress / HOLD_SECONDS

## Returns true on the tick the hold completes. `allowed` is false during the
## collapse and while a screen is up: a block competing with the walk to the
## gate makes both objectives worse.
func tick(dt: float, player_pos: Vector2, allowed: bool, place: Callable,
		rng: RandomNumberGenerator) -> bool:
	elapsed += dt
	if not allowed:
		# Banking nothing is deliberate: a block half-held when the collapse
		# starts would otherwise pay out on the next arena, where it was never
		# earned. next_at moves WITH the despawn — `elapsed` keeps advancing
		# whether or not the block is live, so leaving it stale means the first
		# allowed tick after a disallowed stretch already satisfies
		# `elapsed >= next_at` and spawns instantly.
		if alive:
			next_at = elapsed + INTERVAL
		alive = false
		progress = 0.0
		return false
	if not alive:
		if elapsed >= next_at:
			var ang := rng.randf() * TAU
			var d := rng.randf_range(MIN_DIST, MAX_DIST)
			pos = place.call(player_pos + Vector2(cos(ang), sin(ang)) * d)
			alive = true
			progress = 0.0
		return false
	if player_pos.distance_to(pos) <= RADIUS:
		progress = minf(HOLD_SECONDS, progress + dt)
	else:
		progress = maxf(0.0, progress - DRAIN_RATE * dt)
	if progress >= HOLD_SECONDS:
		alive = false
		progress = 0.0
		next_at = elapsed + INTERVAL
		return true
	return false
```

```gdscript
signal fusion_offered(matches: Array)

enum CardMode { NORMAL, SEEDED, RANK_ONLY }

## How often a block that cannot fuse still hands you the module you are closest
## to needing. Twenty EXACT triples over a 35-module table are not reachable by
## drawing at random — the targeted card is not a bonus, it is the delivery
## mechanism, so the weight is high on purpose.
const TARGETED_ODDS := 0.70

var _pending_fusions: Array = []

func _block_payout() -> void:
	var matches := []
	for m in loadout.matched_recipes():
		if loadout.can_fuse(m[0], m[1].fused):
			matches.append(m)
	# A fusion offer PAUSES the run and waits for choose_fusion/decline_fusion.
	# With nobody connected there is nobody to unpause it, and _physics_process
	# returns early on `paused` forever: the run deadlocks. Every headless driver
	# — perf_milestone0.gd:132, test_run.gd:22, tools/shot_iso.gd:12,
	# tools/screenshot.gd:8 — connects level_up_offered and nothing else, so this
	# guard is what keeps an autopiloted run that happens to assemble a triple
	# from hanging the perf gate. Step 4 also gives those drivers a handler; the
	# design must not depend on their having one.
	if not matches.is_empty() and not fusion_offered.get_connections().is_empty():
		_pending_fusions = matches
		paused = true
		emit_signal("fusion_offered", matches)
		return

	var seed_m := _targeted_module()
	if seed_m != null and _card_rng.randf() < TARGETED_ODDS:
		pending_levels += 1
		_offer_cards(CardMode.SEEDED, seed_m)
		return

	var roll := _card_rng.randf()
	if roll < 0.40:
		salvage += 150 * subnet          # subnet starts at 1 (run.gd:214)
		emit_signal("stats_changed")
	elif roll < 0.70:
		# player_health is the mutable pool; _eff_integrity() is the CAP it is
		# measured against (run.gd:417-418). There is no `integrity` member.
		player_health = minf(_eff_integrity(),
			player_health + _eff_integrity() * 0.25)
		emit_signal("stats_changed")
	else:
		pending_levels += 1
		_offer_cards(CardMode.RANK_ONLY)

func choose_fusion(index: int) -> void:
	# Bounds-checked against the PENDING list, not against the loadout: a stale
	# index from a screen the player already declined must consume nothing, and
	# Loadout.fuse re-checks can_fuse for the same reason.
	if index >= 0 and index < _pending_fusions.size():
		var m = _pending_fusions[index]
		loadout.fuse(m[0], m[1].fused)
		_recompile()
	_pending_fusions = []
	paused = false
	emit_signal("stats_changed")

func decline_fusion() -> void:
	# Declining costs nothing and the recipe stays matched, so the next block
	# offers it again. A fusion is permanent; refusing one must not be.
	_pending_fusions = []
	salvage += 25
	paused = false
	emit_signal("stats_changed")

## The module that would do the most for the build right now: one that completes
## a recipe a row is a single module short of, or failing that one that fills a
## slot keeping a row inert. Must be unlocked and actually placeable.
func _targeted_module() -> Module:
	var mods := ModuleTable.by_id()
	var unlocked := {}
	for m in _unlocked:
		unlocked[m.id] = true
	# The near-miss search itself lives in RecipeTable: it is a question about
	# recipes, and the arena has no business knowing a recipe's shape or an
	# exploit's slots. This function only filters by what is unlocked and
	# placeable, which IS the run's business.
	for ex in loadout.exploits:
		var want := RecipeTable.near_miss(ex)
		if want == &"" or not unlocked.has(want):
			continue
		var cand: Module = mods[want]
		if not loadout.legal_targets(cand).is_empty():
			return cand
	# Nothing is one short: fall back to anything that un-inerts a row.
	for ex in loadout.exploits:
		if not ex.is_inert():
			continue
		var need := Module.Slot.VECTOR if ex.vector == null else Module.Slot.TRIGGER
		for m in _unlocked:
			if m.slot == need and not loadout.legal_targets(m).is_empty():
				return m
	return null
```

```gdscript
func _offer_cards(mode: int = CardMode.NORMAL, seed_module: Module = null) -> void:
	paused = true
	var pool := _card_pool()
	if mode == CardMode.RANK_ONLY:
		# Filter the TARGETS, not just the entries. Keeping a whole entry because
		# it contains a rank-up leaves its EMPTY_SLOT and REPLACE buttons on the
		# card, so the screen is a guaranteed-rank-AVAILABLE screen rather than a
		# guaranteed rank — which is not what the payout promised.
		var ranked := []
		for entry in pool:
			var only := []
			for t in entry[1]:
				if t.action == Loadout.Rule.RANK_UP:
					only.append(t)
			if not only.is_empty():
				ranked.append([entry[0], only])
		if not ranked.is_empty():
			pool = ranked
	for i in range(pool.size() - 1, 0, -1):
		var j := _card_rng.randi_range(0, i)
		var tmp = pool[i]; pool[i] = pool[j]; pool[j] = tmp
	if mode == CardMode.SEEDED and seed_module != null:
		# Front of the deck, not an extra card: the screen still shows three.
		for i in pool.size():
			if pool[i][0] != null and pool[i][0].id == seed_module.id:
				var tmp2 = pool[0]; pool[0] = pool[i]; pool[i] = tmp2
				break
	var cards := []
	for entry in pool:
		if cards.size() >= 3:
			break
		cards.append(entry)
	while cards.size() < 3:
		cards.append([null, []])        # salvage card fallback
	emit_signal("level_up_offered", cards)
```

```gdscript
## One line per recipe the player could actually assemble, with a mark per slot
## against what the loadout holds right now. Recipes whose modules are still
## locked are omitted entirely — the point of the panel is to show what is
## within reach, and a wall of unreachable rows is the opposite of that.
func recipe_lines() -> Array:
	var unlocked := {}
	for m in run._unlocked:
		unlocked[m.id] = true
	var out := []
	for r in RecipeTable.all():
		if not (unlocked.has(r.vector_id) and unlocked.has(r.trigger_id)
				and unlocked.has(r.payload_id)):
			continue
		var marks := ""
		for id in [r.vector_id, r.trigger_id, r.payload_id]:
			marks += "[x]" if not run.loadout._slot_holding(id).is_empty() else "[ ]"
		out.append("%s  %s  %s + %s + %s" % [marks, r.fused.display_name,
			r.vector_id, r.trigger_id, r.payload_id])
	return out
```
