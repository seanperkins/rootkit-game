# Gates Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the instant subnet advance with a gate you can see from the start, walk to, and cross through a corridor.

**Architecture:** An explicit `Phase` on `run.gd` (FIGHTING / CLEARED / TRANSIT) becomes the single source of truth for whether the director steps, replacing the `paused` / `won` / `_advance_pending` triple. The gate is a structure on `Terrain`, generated with the walls and reachability-guaranteed. The corridor is a second `Terrain` instance, so collision and rendering work there for free.

**Tech Stack:** Godot 4.7, GDScript.

**Spec:** `docs/superpowers/specs/2026-08-31-gates-design.md`

## Global Constraints

- `Terrain` stays pure — no nodes, no tree, no signals.
- The gate must be reachable from the player's start on every seed and subnet.
- Subnet 03 (`SpawnDirector.CAMPAIGN_SUBNETS`) has **no gate**: clearing its ICE wins immediately, as today.
- Spawning halts in CLEARED and TRANSIT. The corridor contains no enemies, ever.
- Lingering in CLEARED is free and unlimited.
- The 30% clear heal moves to gate entry; salvage still banks on the ICE kill.
- Both autopilots (`tests/test_run.gd`, `tests/perf_milestone0.gd`) must walk to the gate, or campaign tests hang in CLEARED instead of failing.
- Every new test case marks itself finished on its last line, and the suite fails on a missing mark — a runtime error otherwise aborts one case silently and the suite still exits 0.
- No AI attribution in commit messages.

```gdscript
func the_gate_is_always_reachable() -> void:

	var off_edge := 0
	for s in range(150):

## Reuses the test's own flood fill rather than the generator's.
func _reaches(t: Terrain, from: Vector2, to: Vector2) -> bool:
	var goal := t.cell_index(to)
	var seen := {}
	var stack := [t.cell_index(from)]
	while not stack.is_empty():
		var i: int = stack.pop_back()
		if i < 0 or seen.has(i) or t.solid[i] != 0:
			continue
		seen[i] = true
		if i == goal:
			return true
		var x := i % t.w
		var y := i / t.w
		if x > 0: stack.append(i - 1)
		if x < t.w - 1: stack.append(i + 1)
		if y > 0: stack.append(i - t.w)
		if y < t.h - 1: stack.append(i + t.w)
	return false
```

```gdscript
## The gate goes down AFTER the connectivity fill, and is connected to the
## reachable region by carving a straight line toward the player's start.
##
## Carving, which _fill_unreachable deliberately refuses to do for pockets — and
## the objection does not carry here. A straight line toward a point already
## known to be reachable always terminates and cannot leave a second region
## behind; the general pocket case had neither property. Running after the fill
## rather than before is what keeps that true: the reachable set already exists
## to aim at.
func _place_gate(rng: RandomNumberGenerator, player_start: Vector2) -> void:
	var edge := rng.randi_range(0, 3)
	var cx := 0
	var cy := 0
	match edge:
		0: cx = rng.randi_range(2, w - 3); cy = 1
		1: cx = rng.randi_range(2, w - 3); cy = h - 2
		2: cx = 1; cy = rng.randi_range(2, h - 3)
		_: cx = w - 2; cy = rng.randi_range(2, h - 3)
	gate_pos = origin + Vector2(cx + 0.5, cy + 0.5) * CELL

	# Clear the gate's own cell and its neighbours, so it is a mouth rather than
	# a pinhole you have to hit exactly.
	for y in range(cy - 1, cy + 2):
		for x in range(cx - 1, cx + 2):
			if x >= 0 and y >= 0 and x < w and y < h:
				solid[y * w + x] = 0

	_carve_to(gate_pos, player_start)

func _carve_to(from: Vector2, to: Vector2) -> void:
	var start := cell_index(to)
	if start < 0:
		return
	var seen := _reach(start)
	var i := cell_index(from)
	if i >= 0 and seen[i] != 0:
		return          # already connected; nothing to carve
	var steps := int(from.distance_to(to) / (CELL * 0.5)) + 1
	for k in range(steps + 1):
		var p := from.lerp(to, float(k) / float(steps))
		var c := cell_xy(p)
		if not in_bounds(c):
			continue
		var j := c.y * w + c.x
		solid[j] = 0
		if seen[j] != 0:
			return      # met the reachable region; stop carving
```

```gdscript
const CORRIDOR_LENGTH := 1200.0
const CORRIDOR_HALF_WIDTH := 90.0

## A walled strip with nothing in it, generated on entering a gate and thrown
## away on leaving. A Terrain rather than a bespoke corridor type, so collision,
## the occupancy grid and rendering all work here for free.
static func corridor(length: float = CORRIDOR_LENGTH) -> Terrain:
	var size := Vector2(length + 400.0, 640.0)
	var t := Terrain.new(-size * 0.5, size)
	# Solid everywhere, then cut the walkable strip out of it.
	t.solid.fill(1)
	for y in range(t.h):
		for x in range(t.w):
			var p := t.origin + Vector2(x + 0.5, y + 0.5) * CELL
			if absf(p.y) <= CORRIDOR_HALF_WIDTH:
				t.solid[y * t.w + x] = 0
	t.rects.append([Rect2(Vector2(-length * 0.5, -CORRIDOR_HALF_WIDTH),
		Vector2(length, CORRIDOR_HALF_WIDTH * 2.0)), Kind.WALL])
	t.has_gate = true
	t.gate_open = true
	t.gate_pos = Vector2(length * 0.5, 0.0)
	return t

func corridor_entrance() -> Vector2:
	return Vector2(origin.x + CELL * 2.0, 0.0)
```

```gdscript
## The terrain currently underfoot. Everything that collides or draws asks this
## rather than `terrain`, so the corridor needs no special cases.
```

```gdscript
func _step2c_gate() -> void:
	var f := field()
	if not f.has_gate or not f.gate_open:
		return
	if player_pos.distance_to(f.gate_pos) > Terrain.GATE_RADIUS:
		return
	if phase == Phase.CLEARED:
		_enter_corridor()
	elif phase == Phase.TRANSIT:
		_leave_corridor()

func _enter_corridor() -> void:
	phase = Phase.TRANSIT
	corridor = Terrain.corridor()
	player_pos = corridor.corridor_entrance()
	# The clear heal lands HERE rather than on the ICE kill, so it rewards
	# leaving rather than killing — and once, because the phase has already
	# changed by the time this could be reached again.
	player_health = minf(_eff_integrity(),
		player_health + _eff_integrity() * SUBNET_CLEAR_HEAL)
	for i in range(enemies.count - 1, -1, -1):
		enemies.despawn(i)
	for i in range(projectiles.count - 1, -1, -1):
		projectiles.despawn(i)
	emit_signal("stats_changed")
```

```gdscript
## already empty by the time we get here, because entering the corridor cleared
```

- [ ] **Step 1: Walk to the gate when cleared**

In both autopilots, before the kiting logic:

```gdscript
	# In CLEARED there is nothing left to kite and nothing left to farm, so head
	# for the gate. Without this the autopilot stands in a cleared subnet until
	# the tick budget runs out, and every campaign assertion times out rather
	# than failing — which looks like a hang, not a result.
	if run.phase == run.Phase.CLEARED or run.phase == run.Phase.TRANSIT:
		var f: Terrain = run.field()
		if f.has_gate and f.gate_open:
			return _around_walls((f.gate_pos - run.player_pos).normalized())
```

(In `perf_milestone0.gd` the receiver is `g`, and `_around_walls` takes `g` as its first argument.)
