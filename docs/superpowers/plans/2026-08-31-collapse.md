# Collapse and the Walked Gate — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Rework the subnet transition from a teleport into a walk out of a collapsing arena.

**Architecture:** One BFS distance field from the gate drives both new features — the largest distances are farthest from the gate, so they collapse first, and the descending gradient from the player is a genuine tile route home. The separate corridor `Terrain` and its teleport are deleted: the corridor becomes part of the arena's own grid, which is enlarged past the arena bounds so you can walk out through the gate continuously.

**Spec:** amends `docs/superpowers/specs/2026-08-31-gates-design.md` (see "Amendments" at its end).

## Decisions (from playtest)

| Question | Answer |
|---|---|
| Wall density | Flat **3%**, every subnet. No ramp. |
| Barrier size | Much smaller — 1–3 cells a side, not 2–6 |
| Caught by the collapse | **You die** |
| Does collapse reach the gate | **Yes** — a hard deadline, ~75 s from the boss kill |
| Route display | Lit **tiles** on the ground, not a line |
| Corridor | Contiguous with the arena. **No teleport.** |
| Shards | Cleared on advance — they must not follow you |

## Global Constraints

- Run tests with `tools/run_tests.sh`. A bare `PASS` is not evidence; the runner fails on any `SCRIPT ERROR`.
- Every new test case marks itself finished on its last line.
- The BFS runs **once**, on the boss kill — never per tick.
- Collapse applies only inside the arena proper. The corridor never collapses: it is the way out.
- Perf gate stood at p95 2.176 ms against a 9.649 ms budget.
- No AI attribution in commit messages.

```gdscript
## Distance in cells from the gate, over open ground. -1 where unreachable.
##
## Computed ONCE, on the boss kill, and it earns its keep twice over: the
## largest distances are exactly "farthest from the gate", which is the order
## the arena falls apart in, and the descending gradient from any cell is a
## route home that follows the actual walkable space rather than pointing
## through a wall.
var dist_from_gate: PackedInt32Array
var max_dist := 0
var voided: PackedByteArray

func build_distance_field() -> void:
	dist_from_gate = PackedInt32Array()
	dist_from_gate.resize(w * h)
	for i in dist_from_gate.size():
		dist_from_gate[i] = -1
	voided = PackedByteArray()
	voided.resize(w * h)
	max_dist = 0
	var start := cell_index(gate_pos)
	if start < 0:
		return
	# A plain BFS queue as a PackedInt32Array with a read head, rather than
	# pop_front on an Array — pop_front is O(n) and this runs over 6,300 cells.
	var queue := PackedInt32Array([start])
	var head := 0
	dist_from_gate[start] = 0
	while head < queue.size():
		var i := queue[head]
		head += 1
		var d := dist_from_gate[i] + 1
		var x := i % w
		var y := i / w
		for nb in [
				i - 1 if x > 0 else -1,
				i + 1 if x < w - 1 else -1,
				i - w if y > 0 else -1,
				i + w if y < h - 1 else -1]:
			if nb < 0 or solid[nb] != 0 or dist_from_gate[nb] >= 0:
				continue
			dist_from_gate[nb] = d
			if d > max_dist:
				max_dist = d
			queue.append(nb)

## Void every open cell farther from the gate than `threshold`.
##
## The corridor is exempt: it lies outside the arena rect, and voiding the way
## out would make the deadline unwinnable rather than tense.
func collapse_to(threshold: int) -> void:
	for i in voided.size():
		if solid[i] != 0 or dist_from_gate[i] < 0:
			continue
		var p := origin + Vector2(float(i % w) + 0.5, float(i / w) + 0.5) * CELL
		if not arena_rect.has_point(p):
			continue
		voided[i] = 1 if dist_from_gate[i] > threshold else 0

func is_void(p: Vector2) -> bool:
	var i := cell_index(p)
	if i < 0 or voided.is_empty():
		return false
	return voided[i] != 0
```

```gdscript
## Walk downhill on the distance field, from `p` to the gate.
##
## Lit as TILES rather than drawn as a line, because a line from you to the gate
## is a claim the geometry does not support — it points through walls. Following
## the gradient can only ever tread on ground you can actually walk.
func route_from(p: Vector2, limit: int = 400) -> PackedInt32Array:
	var out := PackedInt32Array()
	var i := cell_index(p)
	if i < 0 or dist_from_gate.is_empty() or dist_from_gate[i] < 0:
		return out
	out.append(i)
	var guard := 0
	while dist_from_gate[i] > 0 and guard < limit:
		guard += 1
		var x := i % w
		var y := i / w
		var best := -1
		for nb in [
				i - 1 if x > 0 else -1,
				i + 1 if x < w - 1 else -1,
				i - w if y > 0 else -1,
				i + w if y < h - 1 else -1]:
			if nb < 0 or dist_from_gate[nb] < 0:
				continue
			if best < 0 or dist_from_gate[nb] < dist_from_gate[best]:
				best = nb
		if best < 0 or dist_from_gate[best] >= dist_from_gate[i]:
			break
		i = best
		out.append(i)
	return out
```
