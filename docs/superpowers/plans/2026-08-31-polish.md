# Polish Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add the feedback layer — shake, hitstop, hit flash, damage numbers,
procedural audio, a panelized HUD, gamepad + pause, preferences, and boss
teleport-in arrivals — without changing a single game mechanic.

**Architecture:** A pure `feel.gd` (`RefCounted`) owns shake trauma, the hitstop
deadline, the damage-number pool and an outbound audio-event list. `run.gd`'s
tick splits: a presentation half above the `run.gd:519` guard that runs every
frame on an unscaled wall clock, and the existing simulation half below it. A
pure `synth.gd` builds `AudioStreamWAV`s; a thin `sfx.gd` node drains feel's
event list. Nothing in the simulation ever references a node.

**Tech Stack:** Godot 4.7, GDScript. No image assets, no font files, no audio
files, no `Area2D`.

**Spec:** `docs/superpowers/specs/2026-08-31-polish-design.md` — read it
alongside this plan; every task argues from it.

## Global Constraints

- **`tools/run_tests.sh` is the only trustworthy verdict.** A suite that prints
  PASS may have aborted; the runner fails on any `SCRIPT ERROR` / `Parse Error`.
  Never run one suite by hand and believe it.
- **`scripts/build/` and the new `feel.gd` / `synth.gd` stay pure** — no scene
  tree, no engine calls beyond `Resource`/`RefCounted`.
- **Per-enemy arrays need BOTH halves of the slot invariant:** zeroed in
  `_spawn_enemy_state`, AND relocated tail-into-slot on despawn.
- **Two despawn sites exist:** `run.gd:1708-1716` (`_step9_recycle`) and
  `run.gd:1802-1804` (`_step2d_collapse`).
- **Every new suite goes into `SUITES` in `tools/run_tests.sh`.**
- **`save.json` is hostile input.** Guard container type, value type, and
  finiteness — `clampf` is not a finiteness check.
- Every new test case marks itself finished on its last line; the suite fails on
  a missing mark. Follow the existing suites' `_check` / `finished` idiom.
- Commit after each task.
